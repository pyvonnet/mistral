Qu'est-ce que le Zen de Python ?

Le Zen de Python (PEP 20, écrit par Tim Peters en 1999) est un ensemble de 19 aphorismes qui résument la philosophie du langage. Il est caché dans Python lui-même : tapez import this dans un interpréteur. Cliquez sur l'œuf ci-dessus pour le voir apparaître !
